## Типичные вопросы и ответы

### Q1: Почему вы выбрали ASP.NET Core вместо других фреймворков?

**A:** ASP.NET Core предоставляет несколько преимуществ:
- Высокая производительность (один из самых быстрых фреймворков)
- Сильная типизация C#, что снижает количество ошибок
- Встроенная поддержка DI (Dependency Injection) и middleware
- Entity Framework Core для работы с БД
- Хорошая документация и поддержка сообщества

### Q2: Как вы обеспечили безопасность приложения?

**A:** 
- JWT токены для аутентификации (stateless)
- BCrypt для хеширования паролей
- Role-based access control (RBAC) для авторизации
- Валидация данных на backend (никогда не доверяем frontend)
- DTO для трансформации данных
- HTTPS для шифрования трафика

### Q3: Как система масштабируется при большом количестве пользователей?

**A:**
- Кэширование с использованием MemoryCache
- Оптимизированные SQL запросы с индексами
- Docker контейнеризация для горизонтального масштабирования
- SignalR для эффективного real-time обновления
- Асинхронное программирование (async/await)

### Q4: Как вы интегрировались с RIMS API?

**A:**
- Создал отдельный RimsIntegrationService
- HttpClient с настроенным timeout и повторными попытками
- Обработка ошибок и логирование при интеграции
- Синхронизация данных сотрудников в фоне

### Q5: Что было самым сложным в разработке?

**A:** 
Самым сложным было реализовать real-time функциональность с SignalR, потому что:
- Нужно было правильно управлять соединениями
- Обработать переподключения при потере соединения
- Оптимизировать количество отправляемых сообщений
- Синхронизировать состояние между backend и frontend
