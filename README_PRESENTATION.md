# LaTeX Презентация для предзащиты ВКР

## Информация о презентации

**Название ВКР:** Система онбординга для новых сотрудников

**Студент:** Фирана Мамедова

**Количество слайдов:** 13

**Формат:** 4:3 (соотношение сторон под проекторы в корпусе)

## Структура презентации

1. **Титульный лист** - Название, ФИО студента, группа, руководитель
2. **Актуальность** - Проблема и её решение
3. **Цель и задачи** - Основные цели и 5 задач из введения ВКР
4. **Технологический стек** - Backend (ASP.NET Core) и Frontend (Vue 3)
5. **Задача 1** - Управление пользователями и ролями
6. **Задача 2** - Модули обучения и интерактивные курсы
7. **Задача 3** - Отслеживание прогресса и аналитика
8. **Задача 4** - Уведомления и коммуникация
9. **Задача 5** - Гамификация, менторство и ИИ
10. **Сложность разработки** - Основные вызовы
11. **Демонстрация** - Место для видео (2-3 минуты)
12. **Заключение** - Выполненные задачи
13. **Структура ВКР** - Оглавление с номерами страниц

## Компиляция

### Требования

- LaTeX дистрибутив (TeX Live, MiKTeX или Overleaf)
- Пакеты: beamer, babel (russian), graphicx, listings, hyperref

### На локальной машине (Windows)

```bash
# С MiKTeX
pdflatex.exe presentation.tex

# Если используете pdflatex несколько раз (для корректных номеров)
pdflatex.exe presentation.tex
pdflatex.exe presentation.tex
```

### На локальной машине (Linux/Mac)

```bash
pdflatex presentation.tex
pdflatex presentation.tex
```

### В Overleaf

1. Создайте новый проект
2. Загрузите файл `presentation.tex`
3. Убедитесь, что в меню Compiler выбран `pdfLaTeX`
4. Нажмите Recompile

## Рекомендации для подготовки доклада

### Время выступления
- **Общее время:** ~7 минут
- **На слайды и речь:** ~5-6 минут
- **На видео-демонстрацию:** 2-3 минуты
- **На вопросы (резерв):** 0-1 минута

### Структура доклада

#### Вводная часть (1 мин)
- Слайд 1-2: Приветствие + Актуальность
- Вкратце описать проблему

#### Основная часть (3-4 мин)
- Слайд 3-10: Цель, задачи, реализация
- Сосредоточиться на **что было сделано самостоятельно**
- Подчеркнуть сложность и масштаб работы

#### Демонстрация (2-3 мин)
- Слайд 11: Видео с работой приложения
- Показать интересные функции

#### Завершение (0.5-1 мин)
- Слайд 12-13: Итоги и структура ВКР

### Советы по представлению

**Что ДЕЛАТЬ:**
- ✓ Говорить естественно, не читать со слайда
- ✓ Делать паузы после ключевых моментов
- ✓ Поддерживать зрительный контакт с аудиторией
- ✓ Быть готовым к вопросам по каждой задаче
- ✓ Иметь под рукой краткие заметки
- ✓ Показывать энтузиазм к своей работе

**Что НЕ ДЕЛАТЬ:**
- ✗ Читать текст слайдов
- ✗ Переходить слишком быстро между слайдами
- ✗ Забывать про видео-демонстрацию
- ✗ Вдаваться в лишние технические детали
- ✗ Использовать малопонятные аббревиатуры

## Персонализация

Перед использованием отредактируйте:

1. **Слайд 1 - Титульный лист:**
   - Заполните имя/инициалы руководителя
   - Проверьте номер группы

2. **Слайд 3 - Цель и задачи:**
   - Убедитесь, что задачи совпадают с введением ВКР
   - При необходимости отредактируйте формулировки

3. **Слайд 13 - Структура ВКР:**
   - Добавьте актуальные номера страниц
   - Добавьте названия глав из вашей ВКР

## Подготовка видео-демонстрации

**Рекомендации:**

1. **Длительность:** 2-3 минуты
2. **Содержание:** Показать наиболее интересную реализованную функциональность
3. **НЕ показывать:** Процесс аутентификации (используется по умолчанию)
4. **Показать:** 
   - Основные возможности приложения
   - Интерактивные компоненты
   - Интеграция ключевых модулей
   - Real-time функции (уведомления)
   - Аналитику/отчеты

**Технические требования:**
- Формат: MP4 или встроенное видео
- Разрешение: минимум 1280x720
- Звук: не требуется
- Сохраните в папке с презентацией

## Вопросы, которые может задать комиссия

**Типичные вопросы и как на них ответить:**

1. **«Почему вы выбрали именно этот технологический стек?»**
   - ASP.NET Core: производительность, типизация C#
   - Vue 3: удобство, быстрая разработка, Composition API
   - SQL Server: корпоративный стандарт

2. **«Как решена проблема безопасности?»**
   - JWT токены, роли и права доступа
   - Хеширование паролей BCrypt
   - Валидация на backend

3. **«Как решена масштабируемость?»**
   - Кэширование данных
   - Оптимизированные SQL запросы
   - Docker для контейнеризации

4. **«Какие были основные трудности?»**
   - Интеграция SignalR для real-time
   - Синхронизация с внешним RIMS API
   - Оптимизация производительности аналитики

## Дополнительные советы по композиции слайдов

**Цвета:**
- Background: White (светлый для читаемости)
- Text: Black (высокий контраст)
- Headers: Dark Blue (профессиональный вид)
- Accents: Dark Blue для элементов

**Шрифты:**
- Основной: Helvetica (sans-serif)
- Размер текста: 11pt (легко читается)
- Headers: Крупнее основного текста

**Структура слайда:**
- Максимум 5-7 пунктов на слайде
- Один главный заголовок
- Минимум визуальных элементов (не отвлекают)
- Номер страницы снизу справа
