# 📚 Полный пакет материалов для подготовки к защите ВКР

## Обзор созданных файлов

Я создал полный пакет материалов для подготовки презентации и доклада к предзащите ВКР. Вот что включено:

### 1. **presentation.tex** - Основная LaTeX презентация
   - ✓ Соотношение сторон 4:3 (под проекторы в корпусе)
   - ✓ Светлый фон (белый) для хорошей видимости
   - ✓ 13 слайдов полной структуры
   - ✓ Номера страниц внизу справа
   - ✓ Без анимаций
   - ✓ Профессиональный дизайн

### 2. **README_PRESENTATION.md** - Подробное руководство по презентации
   - Инструкции по компиляции LaTeX
   - Рекомендации по структуре доклада
   - Советы по композиции слайдов
   - Вспомогательные материалы
   - Типичные вопросы и ответы

### 3. **cue_cards.md** - Заметки докладчика
   - Примерный полный текст доклада (3-4 мин)
   - Ключевые цифры для каждого слайда
   - Типичные вопросы и убедительные ответы
   - Таблица с промежуточными маркерами времени
   - Техники уверенного выступления

### 4. **recommendations_VKR_structure.md** - Рекомендации по структуре ВКР
   - Требования к ВКР (объём, содержание)
   - Рекомендуемая структура всех 7-9 разделов
   - Что должно быть в каждом разделе
   - Рекомендации по написанию
   - Примеры источников для списка литературы

### 5. **defense_checklist.md** - Чек-лист подготовки
   - Контрольный список всех элементов ВКР
   - Требования к презентации
   - Подготовка доклада и репетиции
   - Подготовка отчёта о практике
   - Финальный чек-лист за 24 часа

## Быстрый старт

### Шаг 1: Компилируем презентацию LaTeX

**Вариант 1: В Overleaf (онлайн)**
1. Перейдите на https://www.overleaf.com
2. Создайте новый проект → Upload Project
3. Загрузите файл `presentation.tex`
4. Нажмите Recompile
5. Скачайте PDF

**Вариант 2: Локально (Windows)**
```bash
# Установите MiKTeX с https://miktex.org
# Откройте терминал в папке с файлом и выполните:
pdflatex presentation.tex
pdflatex presentation.tex  # второй раз для корректных номеров
```

**Вариант 3: Локально (Linux/Mac)**
```bash
# Установите TeX Live
sudo apt-get install texlive-latex-full  # Linux
brew install basictex  # Mac
# Затем:
pdflatex presentation.tex
pdflatex presentation.tex
```

### Шаг 2: Персонализируем презентацию

Отредактируйте в файле `presentation.tex`:
- Строка 51: Название ВКР
- Строка 52: Ваше ФИО полностью
- Строка 53: Номер группы
- Строка 54: ФИО руководителя
- Слайд 3: Убедитесь, что задачи совпадают с вашей ВКР
- Слайд 13: Добавьте номера страниц из вашей ВКР

### Шаг 3: Подготавливаем доклад

1. Прочитайте файл `cue_cards.md`
2. Используйте примерный текст доклада
3. Адаптируйте под ваш стиль речи
4. Запомните ключевые цифры
5. Репетируйте 3-4 раза

### Шаг 4: Создаём видео-демонстрацию

- Длительность: 2-3 минуты
- Формат: MP4 (1280x720 минимум)
- Содержание: Интересные функции приложения
- **НЕ показываем:** Просто логин/аутентификацию

Сохраните видео в папке с презентацией для удобства.

### Шаг 5: Проверяем по чек-листу

Используйте `defense_checklist.md` для финальной проверки:
- Все ли элементы ВКР готовы?
- Все ли слайды соответствуют требованиям?
- Готов ли доклад?
- Подготовлены ли дополнительные материалы?

## Структура презентации (13 слайдов)

```
1. ТИТУЛЬНЫЙ ЛИСТ
   └─ Название, ФИО, группа, руководитель

2. АКТУАЛЬНОСТЬ
   └─ Проблема + решение (3-4 пункта)

3. ЦЕЛЬ И ЗАДАЧИ
   └─ 1 цель + 5 задач

4. ТЕХНОЛОГИЧЕСКИЙ СТЕК
   └─ Backend (ASP.NET) | Frontend (Vue3) | Инфраструктура (Docker)

5-9. РЕАЛИЗАЦИЯ ЗАДАЧ (по одному слайду на задачу)
   ├─ Задача 1: Управление пользователями
   ├─ Задача 2: Модули обучения
   ├─ Задача 3: Прогресс и аналитика
   ├─ Задача 4: Уведомления
   └─ Задача 5: Гамификация и ИИ

10. СЛОЖНОСТЬ РАЗРАБОТКИ
    └─ 5 основных вызовов и решений

11. ВИДЕО-ДЕМОНСТРАЦИЯ
    └─ Место для 2-3 минутного видео

12. ЗАКЛЮЧЕНИЕ
    └─ Выполненные задачи (совершённая форма)

13. СТРУКТУРА ВКР
    └─ Содержание с номерами страниц
```

## Типичные ошибки, которых нужно избежать

❌ **НЕПРАВИЛЬНО:**
- Читать текст со слайда
- Анимация на слайдах
- Тёмный фон (плохо видно)
- Слишком много текста на слайде
- Забыть про видео
- Не репетировать доклад
- Указать неправильные даты в отчёте

✓ **ПРАВИЛЬНО:**
- Говорить естественно
- Минимум текста на слайдах
- Светлый фон, тёмный текст
- Тезисы и пункты
- Видео 2-3 минуты
- Репетировать 3-4 раза
- Проверить все даты в документах

4. **Покажите эмоции** - увлечённость заразна
